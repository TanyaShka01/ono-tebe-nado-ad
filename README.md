Это статический одностраничный сайт, реализованный как HTML/CSS. Верхняя часть шапки оформлена в виде белого фона с левой навигацией, центром — логотип, и правой частью — контактной информацией. Главная секция (hero) содержит заголовок из трех строк, без ступеньки, с логотипом по центру.

Содержимое проекта:
- index.html — основная страница, выполняет рендеринг шапки, героя и основного контента.
- styles.css — стили сайта (логика для верхней шапки, типографика, сетки и пр.).
- images/ — изображения:
  - logo.png (логотип, который рендерится в шапке как центрированная иконка)
  - hero-banner.jpg (фон для секции hero, если используется в проекте)
  - chorjects-art-*.jpg (пример изображений для карточек лотов, если применимо)
- script.js — JavaScript для дополнительной функциональности (если есть).
- README.md — этот файл.

Требуется:
- браузер для локального просмотра статической страницы.
- При желании, можно поднять локальный сервер (например, через Live Server в VS Code или http-server).

Как запустить локально
1) Откройте index.html в браузере напрямую или через локальный сервер.
2) Чтобы запустить сервер локально (псевдо-REST статический):
   - Установите Node.js, затем выполнить: npm install -g http-server
   - В терминале перейдите в папку проекта и запустите: http-server -p 8080
   - Откройте http://localhost:8080

Настройка и кастомизация
- Логотип: путь к логотипу задаётся в файле index.html в теге <img src="images/logo.png" ...>. Если у тебя другой путь/имя файла, замени на нужный.
- Логотип по центру шапки: в коде используется центрирование через flex/grid и тег <img> внутри блока логотипа.
- Навигация: слева размещены ссылки, которые указывают на секции с id #home, #lots, #auction. Измени названия пунктов и href по необходимости.
- Контакты: справа в шапке можно заменить телефон, email и адрес на свои данные.
- Фон секции hero: путь указан как images/hero-banner.jpg. Замени на свой файл, если хочешь использовать другой фон.

Структура шапки (пояснение)
- Левый блок: навигация (ul с li и ссылками)
- Средний блок: логотип (img) — путь к файлу logo.png, который должен лежать в images/
- Правый блок: контактная информация (телефон, email, адрес)

Советы по стилю
- В файле index.html можно переключать текст/порядок строк в hero, если нужно изменить визуал.
- Все стили можно вынести в styles.css и подключить как внешний файл, чтобы упростить редактирование.

Поддержка и обновления
- При добавлении новых элементов или секций — просто дополни HTML и CSS, поддерживайте семантику и accessibility (aria-labels и alt-тексты).
